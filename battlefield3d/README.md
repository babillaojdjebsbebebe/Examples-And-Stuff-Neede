# Battlefield Lite 3D (Prototipo)

Prototipo de juego 3D en primera persona hecho con Three.js.

## Qué incluye

- Vista FPS con `PointerLockControls` (WASD + mouse + salto + sprint).
- Mapa amplio con niebla, relieve simple y vegetación.
- Casas y cajas destructibles.
- Enemigos básicos que patrullan y persiguen al jugador.
- Vehículos decorativos: tanque y avión en movimiento.

## Ejecutar

Desde la raíz del repo:

```bash
cd battlefield3d
python3 -m http.server 4173
```

Luego abrir:

`http://localhost:4173`

> Nota: Es un demo "lite" para navegador, no un AAA completo.
